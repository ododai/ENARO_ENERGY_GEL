# ENARO ENERGY GEL Landing Page

Responsive landing page concept for a portfolio project. Built with HTML, CSS, and vanilla JavaScript; intended for GitHub Pages.

## Files
- `index.html` — page content and video player
- `styles.css` — responsive layout and visual styling
- `script.js` — smooth anchor scrolling
- `assets/` — ENARO logo, product images, runner photo, and 20-second ad video

## Run locally in VS Code
1. Extract the ZIP and open the `enaro-landing-site` folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `ENARO_ENERGY_GEL`.
2. Upload the contents of this folder (upload `index.html`, `styles.css`, `script.js`, `README.md`, and `assets/`; do not upload only the outer folder).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the Pages URL to appear. It will usually look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Edit content
- Main headline and page text: `index.html`
- Colors, spacing, responsive design: `styles.css`
- Replace image files in `assets/` and keep the same filenames, or update the corresponding paths in `index.html`.

## Important content note
The product data in this concept uses the brief values: 60 g carbohydrate, 80 mg caffeine, 40 g pouch, and 110 kcal. These values should be verified against the final product formula and nutrition label before any real commercial publication. The project is a fictional portfolio concept, not a live store; purchase buttons currently navigate to the product section.
